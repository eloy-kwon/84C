# 84C 가구 배치

84㎡C 타입 평면을 mm 단위로 재구성해 가구를 2D/3D로 배치하고, 각 방에 들어가는지 확인하는 단일 HTML 페이지입니다.

- 게시 페이지: https://claude.ai/artifact/GmorWqk8gtNu79iP9c36LE
- 소스: `plan84c.html` (의존성은 Three.js r128 CDN 하나)

## 기능

- 2D 평면: 드래그 이동, `R` 회전, `Del` 삭제, 방향키 50mm 이동, 휠/핀치 확대
- 3D 입체: 벽·바닥·창·가구를 입체로 표시 (편집은 2D에서)
- 가구 프리셋 24종 + 직접 입력(이름·가로·세로·높이·색)
- 판정: 들어감 / 다른 가구·설비와 겹침 / 방 밖으로 나감, 선택한 가구의 네 벽까지 거리
- 방별 현황: 면적, 가구 바닥면적 비율, 자동 정렬, 방 치수 수정
- 저장: claude.ai 아티팩트 공유 저장소(`db` 기능)에 자동 저장, 브라우저 저장은 오프라인 대비용, JSON 내보내기/불러오기

## 평면 데이터

`plan84c.html` 상단 스크립트의 `ROOM_DEFS`, `FIXTURES`, `VOIDS`, `OPENINGS`, `WINDOWS`가 평면 정의입니다. 좌표는 침실3 남서쪽 안쪽 모서리가 원점이고 x는 동쪽, y는 북쪽으로 증가합니다. 침실3·침실2·거실·안방과 그 창·문은 손글씨 실측 도면(`ref/measured-plan-annotated.jpg`) 값이고, 나머지는 실측 시트와 분양 도면 기준이라 세대별 오차가 있습니다.

## 게시 방법

파일을 고친 뒤 claude.ai 아티팩트에 같은 URL로 다시 게시하면 됩니다. 공유 저장소 기능은 claude.ai 아티팩트 뷰어 안에서만 동작하므로, GitHub Pages 등 다른 곳에 올리면 브라우저 저장만 됩니다.
